Project: NihArts

About:

NihArts is a full-stack e-commerce web application for a handmade arts and crafts business. It sells nine product categories: Embroidery Hoops, Lippan Art, Pipe Cleaner Bouquets, Keychains, Flower Pots, Hairbands, Clutches, Dancing Flowers, and Fridge Magnets. Two separate interfaces share one backend and database:

  • Customer storefront – browse, buy, and review products.
  • Seller/admin dashboard – manage products, categories, and orders.

Description:

This project includes:

  • Frontend (React + Vite, Tailwind CSS) – Registration and login with validation, product catalog with category filters, cart, checkout with GPS address detection, order history, and photo reviews for delivered orders.
  • Backend (Node.js + Express) – REST API with JWT authentication, bcrypt password hashing, and email OTP for password reset.
  • Database (MongoDB Atlas) – Stores users, products, categories, orders, and reviews.
  • Payments (Razorpay) – Secure checkout with payment signature verification.
  • Admin dashboard – Live sales stats, product and category management, and order status updates.
  • Deployment – Frontend on Vercel, backend on Render, and product images on Cloudinary.

Project: BrewDash 🚀

About:

BrewDash is a full-stack food delivery platform with separate seller, delivery, and admin panels. It offers real-time order tracking with Socket.io and secure online payments with Razorpay.

Features:

  • User registration, login, profile, orders, and live order tracking
  • Seller dashboard with product management and file uploads
  • Admin panel and a delivery partner app
  • Real-time location updates for deliveries
  • Hiring applications
  • Email and SMS notifications

Description:

This project uses:

  • Backend: Node.js, Express.js
  • Database: MongoDB (Mongoose)
  • Real-time: Socket.io
  • Payments: Razorpay
  • Security: Helmet, rate limiting, Mongo-sanitize
  • Frontend: HTML, CSS, JavaScript
  • Notifications: Nodemailer, Twilio

Project: Disease Name Prediction

About:

A distributed machine-learning system that predicts disease names from clinical or medical data. It covers the full pipeline from data ingestion and preprocessing to model training, evaluation, and serving predictions through a REST API.

Features:

  • End-to-end pipeline: data ingestion, preprocessing, training, evaluation, and serving
  • Distributed training support (multi-node / multi-GPU)
  • REST API that returns the predicted disease name with a confidence score
  • React frontend for interactive predictions
  • Evaluation with accuracy, precision, recall, F1-score, and confusion matrix

Description:

This project uses:

  • Languages: Python, Java, C++
  • ML: PyTorch or TensorFlow, pandas, scikit-learn
  • Backend / API: FastAPI (Python)
  • Frontend: React
  • Database: PostgreSQL / MySQL (SQL)
  • Deployment: Docker, Kubernetes (optional)
